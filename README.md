# Very Simple Projects

A collection of small Python projects I created while learning Python.

These projects are simple by design. They were created to practice basic Python concepts and programming fundamentals.

## Projects

### `compare_numbers.py`

Compares two numbers and determines which one is greater, or whether they are equal.

### `grade_average.py`

Takes several grades as input and calculates their average.

### `negate_number.py`

Takes a number and returns its opposite.

### `point.py`

A simple `Point` class for working with coordinates and basic operations and comparisons.

### `user_info.py`

Takes a first name and last name from the user and displays the entered information.

## Requirements

* Python 3.x
* No external packages are required.

## Note

These are small learning projects and are not intended to be production-ready software.
